# VIDEO PROD.

Sitio web de una productora audiovisual, desarrollado con HTML. La página reproduce la estructura de una sola vista con navegación por secciones, catálogo de videos, servicios, información de contacto, inicio de sesión y enlaces a redes sociales.

## Estructura del proyecto

```
trabajoHTML/
├── index.html      Estructura y contenido del sitio
└── assets/         Recursos gráficos (imágenes, logotipos, iconos)
```

## Secciones

1. **Encabezado**: logotipo de VIDEO PROD. y menú de navegación.
2. **Inicio**: presentación con tres tarjetas de videos.
3. **Sobre nosotros**: descripción de la productora y botón "Nuestra Historia".
4. **Servicios**: servicios de grabación y de estudio con imagen destacada.
5. **Contacto**: celular, correo, dirección y mapa.
6. **Inicio de sesión**: formulario de acceso con nombre y contraseña.
7. **Sitios de interés**: accesos a YouTube, TikTok e Instagram.
8. **Pie de página**: logotipo, copyright y enlaces rápidos.

## Tecnologías

- HTML5 semántico

## Cómo ejecutar

Abre `index.html` directamente en el navegador para visualizar el sitio web.

## Personalización

- Reemplaza los bloques de imagen por fotografías reales dentro de `assets/`.
- Actualiza los datos de contacto, videos y enlaces sociales en `index.html`.
- El formulario de inicio de sesión es demostrativo y no envía datos a un servidor.
